County list
The twelve counties named for this build are marked "named". The other eleven are the remaining Texas counties in the EIA Drilling Productivity Report Eagle Ford region. That region, in the local workbook data/raw/production/eia_dpr.xlsx sheet RegionCounties, is Texas only. Oklahoma and Louisiana are not in it.

RRC oil-and-gas district for each county: https://www.rrc.texas.gov/about-us/locations/oil-gas-counties-districts/

Production
Railroad Commission Form PR gas-disposition tapes already on disk and used by src/load_permian.py:
  data/raw/rrc/olf102
  data/raw/rrc/gsf102
Catalog page cited by that loader: https://www.rrc.texas.gov/resource-center/research/data-sets-available-for-download/
src/load_permian.py records these same tapes as posted 2026-09-26. The tape files themselves do not carry a separate posting date in this checkout. Each lease is its latest month on the tape. The drawn month is June or July 2026. MMcfd is that month's Mcf divided by the days in the month, then by 1,000. The tape has one vented-or-flared column.

  https://mft.rrc.texas.gov/link/d551fb20-442e-4b67-84fa-ac3f23ecabb4
  saved as data/raw/rrc/wells/wellXXX.zip
Those zips were downloaded on 2026-09-27. The file listing did not print a separate posted date, so wells_posted in summary.json is blank.
A well is kept only when the oil-lease or gas-well number in the right-hand block of the API line matches a Form PR row in RRC districts 01, 02, 03, 04, or 05 and the lease name on that row is in the API line. The circle is the average of LAT83/LONG83 for the matched surface wells. The check uses districts 01-05 rather than the single column slice in src/load_permian.py because these county files are dominated by records whose lease block starts further left than the Permian records that begin with 3.

Other layers
Pipelines and transmission lines are rows already in db/us_pipelines.sqlite. A feature is kept when one of its vertices falls inside one of the counties above. Pipeline centerlines are the EIA compilation from January 2020, as documented for this database.
Tie-in points are rows in that database's interconnects table whose coordinates fall inside one of the counties. The table's method text is: each point is the midpoint of a public 230 kV-or-higher transmission line within 3 miles of a natural gas pipeline midpoint, thinned to the highest voltage in each roughly 15-mile cell.
Points of interconnection use the same services as src/build_pois.py, then keep points inside these counties:
  https://services1.arcgis.com/7DRakJXKPEhwv0fM/arcgis/rest/services/Electric_Substations/FeatureServer/0/query
  https://services2.arcgis.com/FiaPA4ga0iQKduv3/arcgis/rest/services/US_Electric_Power_Transmission_Lines/FeatureServer/0/query

Hub assignments and prices. The database hub "Agua Dulce" has an approximate center from the public EIA trading-hub layer, Period 202002: 27.748898758, -97.625403621. hub_prices has no Agua Dulce rows. pipeline_hub_links has no Agua Dulce rows. No operator-to-hub assignment and no price was added.
